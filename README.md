 # 🧠 EmotiSense — NLP-Based Text Emotion Classification

**Developed by Okasha Amir**

EmotiSense is an experimental Natural Language Processing (NLP) application that classifies the emotion expressed in an English text message. It uses a trained Machine Learning model and a Streamlit interface to provide single-text predictions and batch predictions from CSV files.

## 🎯 Supported Emotions

EmotiSense identifies six emotion categories:

- 😊 Joy
- 😢 Sadness
- 😠 Anger
- 😨 Fear
- ❤️ Love
- 😲 Surprise

## ✨ Features

- **Single Text Prediction:** Enter a sentence or paragraph and receive a predicted emotion.
- **Emotion Scores:** View the model's estimated scores for the available emotion classes.
- **Batch Analysis:** Upload a CSV file containing multiple text entries and classify them simultaneously.
- **CSV Export:** Download the results of bulk emotion predictions.
- **Model Information:** View the selected algorithm, feature extraction method, number of emotion classes, and saved evaluation metrics.
- **Interactive Interface:** A user-friendly application developed using Streamlit.

## ⚙️ Machine Learning Workflow

The project notebook documents the following training and evaluation workflow:

1. Load and inspect the Kaggle emotion dataset.
2. Clean text consistently for training and inference.
3. Retain stopwords so important negation words such as `not`, `no`, and `never` are not removed.
4. Encode the six emotion labels.
5. Split the data into stratified training and testing sets.
6. Convert text into numerical features using TF-IDF.
7. Train and compare Machine Learning classifiers, including:
   - Multinomial Naive Bayes
   - Logistic Regression
   - Linear Support Vector Machine (SVM)
8. Evaluate models using accuracy, precision, recall, macro F1-score, weighted F1-score, and confusion matrix.
9. Export the selected trained model and supporting metadata into `emotion_model.joblib`.

## ⚠️ Evaluation and Limitations

EmotiSense is an experimental text emotion classification project.

Its performance should be evaluated using the results generated by the exact model artifact deployed in the application.

The project uses a Kaggle dataset for training and evaluation. Manual test examples are also used to investigate how the model behaves on different writing styles.

Some emotion categories, particularly Love and Surprise, have been more challenging during manual testing.

Current limitations include:

- Difficulty distinguishing emotions with similar vocabulary.
- Limited understanding of sentence context and sarcasm.
- Performance variation on text that differs from the training dataset.
- Predictions may not accurately represent a person's actual emotional state.

The displayed probability scores are model estimates, not guarantees of prediction correctness.

EmotiSense is not designed to diagnose mental-health conditions.
